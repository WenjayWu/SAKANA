# SAKANA 补充采购指南

> README 的 BOM 表中，模块类元件（MCP4725、ADS1115、LDO 等）都附了链接，但**树莓派 Pico、电阻、电容**没有给链接。
> 这些是电子领域最通用的标准件，任何店铺都能买到，不存在"指定货源"。本文档给出它们的具体规格、搜索关键词和购买渠道。

**先确认你要做哪个版本**：建议直接做 **v2.0**（噪声低一个数量级，且 README 顶部的重大更新就是针对它的）。下文以 v2.0 为准，并标注 v1.0 的差异。

---

## 1. 树莓派 Pico（1 块）

| 项目 | 说明 |
|---|---|
| 买什么 | **Raspberry Pi Pico（RP2040 芯片）**，建议选 **Pico H**（出厂已焊排针）或"Pico + 排针" |
| 淘宝搜索词 | `树莓派 Pico`、`Raspberry Pi Pico RP2040` |
| 参考价格 | 原装约 30~40 元；RP2040 兼容板约 10~20 元 |
| 哪里买 | 微雪（Waveshare）、亚博智能、DFRobot、Seeed 等树莓派代理店；立创商城也有 |

**注意事项：**

- **兼容板可以用**。本项目不用 Pico 自带的 ADC（它噪声太大，正是作者改用外置 ADS1115/INA219 的原因），所以国产兼容板最大的短板恰好不影响。只要确认引脚布局与官方 Pico 一致（双列 2×20P、2.54mm 间距）即可。
- **不要买 Pico W**（带 WiFi，贵且用不上）；**Pico 2（RP2350）未经作者验证**，保险起见选 RP2040 的经典 Pico。
- 裸板 Pico 没有排针，需要自己焊——第一次焊接拿排针练手正合适。焊完排针的 Pico 插到 PCB 的排母上（见实物照片）。
- **到手后的固件准备**：按住 Pico 上的 BOOTSEL 键插入 USB，电脑会出现一个 U 盘，把 MicroPython 固件（.uf2 文件，从 micropython.org 的 Pico 页面下载）拖进去即完成刷机；之后再把 `Sources/main.py` 上传到 Pico（可用 Thonny 这个免费软件，对新手最友好）。

## 2. 电阻（1/4W 金属膜、1%、直插）

从 PCB 丝印和实物照片确认：板上全部是**直插（轴向）1/4W 金属膜电阻**，就是最常见的蓝色小圆柱。阻值都是标准 E24 系列，随便买。

| 阻值 | v2.0 用量 | v1.0 用量 | 备注 |
|---|---|---|---|
| 1 kΩ | 1 | 1 | |
| 4.7 kΩ（4k7） | 4 | 4 | |
| 6.8 kΩ（6k8） | 2 | 2 | |
| 10 kΩ | 5 | 5 | |
| 15 kΩ | 2 | — | 仅 v2.0 需要 |
| 68 kΩ | — | 1 | 仅 v1.0 需要 |
| 680 kΩ | 1 | 1 | |

**买法（二选一）：**

- **买单阻值**：淘宝搜 `1/4W 金属膜电阻 1% 10K`（换成对应阻值），一般 10~20 只一份、几毛钱，每种阻值来一份。
- **买电阻包**（推荐）：搜 `1/4W 金属膜电阻包 常用阻值`，十几块钱含几十种常用阻值各若干只，本项目 7 种阻值全在里面，以后做别的也用得上。

> 选金属膜 1% 而不是更便宜的碳膜 5%：反馈电阻的精度直接决定电流测量量程的准确度，而两者差价可以忽略。

## 3. 电容（直插独石电容、50V）

板上黄色圆片状元件是**直插独石电容（MLCC）**，脚距 5.08mm。独石电容外壳印着三位数代码，对照如下：

| 容值 | 代码 | v2.0 用量 | v1.0 用量 | 备注 |
|---|---|---|---|---|
| 0.1 µF（100 nF） | 104 | 10 | 10 | 去耦/滤波主力 |
| 1 µF | 105 | 3 | 3 | |
| 2.2 µF | 225 | 2 | — | 仅 v2.0 需要（LDO 输入输出） |
| 68 nF | 683 | 1 | 1 | |
| 10 µF | 106 | 2 | 2 | 可用直插铝电解替代，**注意正负极**，耐压 ≥16V（建议 25V/50V） |

**买法**：淘宝搜 `独石电容 104 50V`（换对应代码），或搜 `独石电容包` 一次买齐。电路最高电压只有 ±6V，耐压 50V 的独石电容绰绰有余。独石/瓷片电容**没有极性**，插反没关系；只有电解电容有极性。

## 4. 最省事的方案：立创商城一键配单（推荐）

BOM 表里 GM1204/GM1206 两个 LDO 的链接本来就是**立创商城**（szlcsc.com）的，而 `Hardware/v2.0/ProPrj_SAKANA_2026-03-20.epro2` 是**立创EDA 专业版**工程文件。因此可以：

1. 下载免费的**立创EDA 专业版**，打开该工程；
2. 在原理图页选择**导出 BOM**——每个元件都带立创商城订货编号（C 码，如 C15849）；
3. 把 BOM 上传到立创商城的**BOM 配单**功能，电阻、电容、LDO、INA219 芯片一键加购物车，一单发货、保证正品；
4. PCB 顺便用 Gerber 文件在**嘉立创**下单打样（每月有免费额度，打样时留意选 2 层板、1.6mm 厚度即可，其余默认）。

## 5. 两个容易踩的坑

**① INA219 的采样电阻（README 第 5 节）**

INA219 需要把默认 0.1 Ω 采样电阻换成 **10 Ω、1% 精度**，否则电流分辨率不够。两条路线：

- **v1.0 路线（对零基础更友好）**：买商品 INA219 模块（BOM 有链接），用烙铁/热风枪取下板上的 0.1 Ω 贴片电阻，换上 10 Ω（贴片，0805 或 1206 封装，淘宝搜 `贴片电阻 0805 10R 1%`）。商品模块直接插杜邦线就能用。
- **v2.0 路线（作者的最终方案）**：作者自制了一块 INA219 贴片小板插在主板上。这块小板的设计**包含在 epro2 工程里**（工程内共 3 块板），但 `Gerber_SAKANA_PCB.zip` 里**只导出了主板**——需要在立创EDA 中打开工程，自行导出小板的 Gerber 去打样。板上是 INA219AIDCNR（SOT-23-8）+ 0603 贴片阻容，**需要热风枪**，对第一次焊接的人有难度。

> 建议：零基础可以先用商品模块（v1.0 路线）把整机跑通，之后再考虑自制小板。主板上 INA219 位置的接口顺序需与模块引脚核对后再插。

**② v2.0 的两个 LDO 是贴片**

GM12043AKCZ-R7（SOT-223-6）和 GM1206AUJZ-R7（SOT-23）封装很小，README 已提醒需要**热风枪**。如果完全没有贴片焊接经验，可以在 B 站搜"热风枪 焊接 SOT-223"先看几个视频，并多买 1~2 颗备损（它们单价不到一块钱）。

## 6. 补充采购清单速查（v2.0）

- [ ] Raspberry Pi Pico（H 版或自焊排针） ×1 —— 淘宝搜 `树莓派 Pico`
- [ ] 1/4W 金属膜电阻 1%：1k、4.7k×4、6.8k×2、10k×5、15k×2、680k —— 淘宝搜 `1/4W 金属膜电阻包`
- [ ] 独石电容 50V：104×10、105×3、225×2、683×1、106×2 —— 淘宝搜 `独石电容包`（106 可用 10µF/25V 电解替代）
- [ ] 10 Ω 1% 贴片电阻（INA219 采样电阻） —— 淘宝搜 `贴片电阻 0805 10R 1%`
- [ ] 其余模块（MCP4725、ADS1115、INA219、DC/DC、OP297×2、继电器×3、CH340、GM1204/GM1206、共模扼流圈、GX16 插座+屏蔽线）—— 直接用 README BOM 表里的链接

**预算参考**：Pico ≈ 35 元，电阻电容（买元件包）≈ 25~30 元，补充项合计约 60~70 元；加上 README 里带链接的模块，整机物料约 100~150 元。

## 7. 给第一次买元件的人几句话

- 同一店铺尽量凑单（元件店通常满几块钱就包邮），电阻电容挑一家卖元件包的店一次搞定。
- 每种元件**多买几只备损**：第一次焊接烫坏、掰断引脚都很正常，而它们单价是"分"。
- 收到后不用急着分辨阻值/容值：电阻看色环（手机搜"电阻色环计算器"，拍照对照），独石电容直接看印字代码，焊接时**以 PCB 丝印上标注的数值为准**逐个对号入座。
