# 给化学工作者的电子学补习路径

> 目标：**读懂 SAKANA 的 README，并能把仪器做出来、调通**。
> 这不是一份电子工程课程表——你不需要系统学《模拟电子技术》和《数字电子技术》。
> 原则是**按需学习（just-in-time）**：以 README 为纲，遇到不懂的概念定点突破，配合仿真和动手验证。

---

## 0. 先说两个好消息

1. **你已经懂了一半。** 恒电位仪"要做什么"你非常清楚：控制 WE 相对 RE 的电位、测量流过 WE 的电流。README 讲的只是"怎么用运放实现它"。
2. **电路里的核心概念你都有现成的类比：**
   - 电压永远是**相对值**——电路里的 GND（地）就是全电路共用的"参比电极"，所有电压都是相对它测的，和电化学里电位相对参比电极定义完全同构；
   - 欧姆定律 ≈ 传质/导电的线性响应；"阻抗"这个词本来就是从电学借到电化学的（EIS 你大概不陌生）。

## 1. 知识地图：按优先级分三档

### 第一档：必修（不懂就读不懂 README）

| 主题 | 要掌握到什么程度 | README 哪里用到 |
|---|---|---|
| 电压、电流、电阻、欧姆定律、分压 | 会算 R 上的压降、会算分压比 | 全文 |
| 电位与"地"的概念 | 理解所有电压都是相对 GND | 全文 |
| **运算放大器**：负反馈、虚短虚断 | 能用"虚短虚断"推出跟随器、反相放大器、加法器的输出公式 | 第 2、5 节（全文核心） |
| **跨阻放大器（TIA）** | 理解"电流进、电压出，增益 = 反馈电阻" | 第 5 节电流采样 |
| RC 电路 | 理解时间常数 τ=RC、低通滤波、截止频率 1/(2πRC) 的**定性含义** | 第 2、9 节 |
| 供电常识 | 单电源 vs 正负双电源、为什么运放输出超不过电源电压、"轨到轨"的含义 | 第 4 节 |

### 第二档：概念级了解即可（知道"是什么、为什么需要"，不用会设计）

- **PWM**：方波占空比 → 平均电压；为什么滤波后仍有纹波（README 第 2、4 节的"失败"就是讲这个）
- **ADC / DAC**：分辨率（12 位 = 4096 级）、采样率、量程的概念
- **I2C 总线**：两根线（SDA/SCL）、每个设备有地址、多个设备可以挂在一起——所以 MCP4725、ADS1115、INA219 能共用 2 根线（README 第 5 节）
- **LDO 与纹波**：开关电源噪声大、LDO 输出干净；共模扼流圈和屏蔽线是干什么 的（第 9 节）
- **去耦电容**：为什么每个芯片电源脚旁边都贴一个 0.1 µF——这就是 BOM 里 104 要 10 个的原因

### 第三档：本次不用学

- 三极管放大电路设计、频率响应/伯德图、数字逻辑门、FPGA、信号完整性……统统跳过。以后有兴趣再说。

## 2. 推荐资源（按"先看哪个"排序）

### ① Falstad CircuitJS 在线仿真 —— 本路径的第一推荐

- 网址：https://www.falstad.com/circuit/ （免费、免安装、浏览器直接跑）
- 它把电流画成**流动的小点**，电压用颜色表示——对零基础者是理解电路最快的方式，没有之一。
- **用法**：学到哪个电路就把它搭出来。菜单 Circuits → Op-Amps 里直接有现成的跟随器、反相放大器；把 README 图 3/4 里的电路复现出来，拖一拖电阻值，看输出怎么变。
- 建议把这三个电路玩到"不用想就能说出输出与输入的关系"：跟随器、反相放大器、跨阻放大器（电流源 + 运放 + 反馈电阻）。

### ② 可汗学院《电路学》（Khan Academy）

- 免费、有中文字幕（B 站也能搜到搬运版），从欧姆定律讲到 RC 电路。
- **只看**：欧姆定律、串并联、分压、电容充放电、RC 电路这几章。每章 10 分钟量级。

### ③ 运算放大器专题（二选一）

- **B 站搜"运算放大器 虚短虚断"**：大量 20~40 分钟的入门视频，挑播放量高的看 2~3 个即可；
- 或看**清华大学《模拟电子技术基础》（华成英）公开课**中的"集成运放""负反馈放大电路"两章（B 站有全集）——这是国内模电标准课，**只看你需要的章，不要从头刷**。

### ④ 用你熟悉的语言讲运放的桥：Bard & Faulkner《电化学方法：原理和应用》

- 中译本（邵元华等译）里有专门的**仪器章节**（"Electrochemical Instrumentation"），用恒电位仪、加法器、电流跟随器把运放电路讲了一遍——**受众就是电化学工作者**，是你和这本 README 之间最好的桥梁。实验室或图书馆大概率有。

### ⑤ 动手向入门书（可选）

- Charles Platt《Make: Electronics》（有中文引进版）：完全从"点亮第一个 LED"做起的实验书，配面包板实验，适合边做边学。

### ⑥ 工具书（不要通读，当字典查）

- Horowitz & Hill《The Art of Electronics》（中译《电子学》）：电子工程师的圣经，近 1000 页。遇到任何概念查对应的节即可。

### ⑦ 查缺补漏

- 网站：**electronics-tutorials.ws**（运放、RC 滤波教程写得极好，英文）；**All About Circuits**（免费在线教科书，英文）。
- 遇到术语的直接搜索法：`术语 + 原理/动画/通俗易懂`，例如 `I2C 原理 动画`、`LDO 和 DCDC 区别`。

## 3. 需要练的三项动手技能

| 技能 | 怎么练 | 备注 |
|---|---|---|
| **万用表** | 学会测电压（DC 档）、通断（蜂鸣档）、电阻 | 几十块的国产表就够用；调试期 90% 的问题靠它定位 |
| **电烙铁焊接** | B 站搜"直插焊接 教程"，买一块几块钱的"焊接练习板"先练 | 本项目主要是直插件，难度低；v2.0 的 LDO/INA219 小板是贴片，需要热风枪，放到最后再碰 |
| **面包板** | 理解中间两排孔的连通规则（每列 5 孔互通、两侧电源排横向互通） | README 第 6 节就是面包板阶段 |

示波器**不是必须的**：有最好（看噪声和波形，README 里多处波形图就是示波器拍的），没有也能完成整机——校准时 SakanaController 软件本身就能显示数据。

## 4. 五周计划（业余每周 3~5 小时）

> **第 1 周就把元件全部下单**（见 [parts-shopping-guide.md](parts-shopping-guide.md)），快递路上正好学习。

**Week 1 — 电路地基 + 采购**
- 可汗学院电路学前几章（欧姆定律、分压、电容）；理解"地"的概念；
- 学会用万用表；买好电烙铁并在练习板上焊 20 个焊点；
- **下单所有元件 + 嘉立创打样 PCB**；下载立创EDA 并打开 v2.0 工程逛一逛。

**Week 2 — 运算放大器（本项目的心脏）**
- 看资源 ③ 的运放视频；用 Falstad 把跟随器、反相放大器、加法器、跨阻放大器各搭一遍；
- 重读 README 第 2 节——这次跟着"设通过 R4 的电流为 i…"的推导走一遍，应该能看懂了；
- 翻一翻 Bard & Faulkner 的仪器章节做对照。

**Week 3 — 信号与模块**
- 概念扫盲：PWM、ADC/DAC、I2C、纹波与 LDO（各花 20 分钟搜索+视频即可）；
- 重读 README 第 4、5 节（PWM 为什么失败、为什么换 ADS1115/INA219）；
- 元件到货后：给 Pico 刷 MicroPython、焊排针，在面包板上先接 Pico + MCP4725，让它输出一个电压并用万用表验证——这是整机的"Hello World"。

**Week 4 — 面包板整机**
- 按 README 第 6 节接线图搭完整电路；
- 装 SakanaController（Releases 有编译好的 exe），先做**校准**（应得到一条斜向下的直线——这一步没过，就回头用万用表逐点查供电和接线）；
- 校准通过后测赤血盐/黄血盐的 CV，和 README 的图对比。

**Week 5 — 转移到 PCB（可选但强烈推荐）**
- 直插件焊接原则：先矮后高（电阻 → 独石电容 → 排针/排母 → 模块），焊完一类用万用表蜂鸣档抽查；
- 贴片部分（GM1204/GM1206、INA219 小板）留到最后，需要热风枪；
- 整机复测校准 + CV；装外壳（`Hardware/*/Shell*` 可 3D 打印）。

## 5. 调试排障的基本思路（遇到问题时回来读）

1. **先查供电**：万用表 DC 档测各模块电源脚——Pico 的 3.3V/5V、DC/DC 的 ±6V（v1.0）或 LDO 的 ±5V（v2.0）对不对。供电不对，后面一切都是白费。
2. **校准不过 → 分段定位**：把 RE 和 CE 短接（README 要求如此）后，从 MCP4725 输出 → 运放输入 → 运放输出 → RE 端子，逐点测电压，哪一级断了就是哪一级的问题（虚焊、面包板接触不良最常见）。
3. **曲线噪声大**：先看接线是不是晃（面包板接触不良是 README 点名的问题），再看屏蔽线和接地。
4. **软件连不上**：CH340 驱动装没装、串口选没选对（设备管理器里看 COM 号）、TX/RX 是不是接反了（要交叉：模块 RX 接 Pico TX）。

## 6. 术语速查表（读 README 卡壳时翻这里）

| 术语 | 一句话解释 |
|---|---|
| 运放（Op-Amp） | 高增益差分放大器，配负反馈后成为各种运算电路的核心 |
| 负反馈 | 把输出接回反相输入端，使电路稳定且特性由外部电阻决定 |
| 虚短 / 虚断 | 负反馈下两输入端电位相等（虚短）、且没有电流流入输入端（虚断）——分析一切运放电路的两把钥匙 |
| 跟随器 | 输出 = 输入的缓冲级，用于隔离前后级 |
| 跨阻放大器（TIA） | 输入电流 × 反馈电阻 = 输出电压；电流测量的标准电路 |
| PWM | 用方波占空比表示模拟量的技术 |
| 纹波 | 直流电压上残留的微小周期性波动 |
| RC 滤波 | 电阻 + 电容组成的低通滤波器，τ = RC 决定反应快慢 |
| ADC / DAC | 模拟→数字 / 数字→模拟转换器；ADS1115 是 ADC，MCP4725 是 DAC |
| I2C | 两根线（SDA 数据 + SCL 时钟）的芯片间通信总线，靠地址区分设备 |
| LDO | 低压差线性稳压器，输出干净的直流电压 |
| 共模扼流圈 | 滤除两根线上同方向干扰的磁性元件 |
| 去耦电容 | 贴在芯片电源脚旁的小电容，就地吸收电源波动（那 10 个 104） |
| 杜邦线 / 排针 / 排母 | 面包板和模块间互连的标准插接件 |
| 直插 / 贴片（SMD） | 两种元件封装形式：带长引脚穿孔焊接 vs 焊在板表面的小方块 |
